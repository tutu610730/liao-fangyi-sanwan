<div class="kicker">深耕在地・第一線服務</div>
<h1>深耕三灣，守護家園</h1>
<h2>清廉・務實・三灣興</h2>
<div class="candidate">廖芳毅 <small>參選三灣鄉長</small></div>
<div class="subline">候選人資訊・經歷・理念與政策主張</div></header>
<main>
<p class="lead">我是廖芳毅，是在三灣長大的孩子。從大河國小、三灣國中，到北上求學、投入警政消防與行政工作，民國104年，因為父母的一聲牽掛，我選擇回到三灣。</p><div class="profile-grid"><div class="profile-box"><h4>在地與學經歷</h4><p>三灣在地成長；就讀大河國小、三灣國中，後北上求學，投入警政、消防與行政工作。</p></div><div class="profile-box"><h4>返鄉服務</h4><p>民國104年返鄉，進入三灣鄉公所擔任清潔隊長，從第一線公共服務累積地方治理經驗。</p></div></div>
<p>回家，不只是陪伴父母。我進入三灣鄉公所擔任清潔隊長，從最基層、最貼近鄉親生活的地方重新開始。</p>
<div class="quote">每天清晨，垃圾車走過的，不只是一條條道路，更是一戶一戶人家的生活。</div>
<p>一袋垃圾、一處髒亂、一通陳情電話，看起來都是小事；但對正在等待處理的鄉親來說，就是今天最重要的事。這些年的第一線工作，讓我更加明白：地方治理，要從願不願意把鄉親的小事，當成自己的事開始。</p>
<section class="section" id="belief">
<div class="num">01 / 我的承諾</div><h3>清廉，是對鄉親最基本的交代</h3>
<p>我主張不買票、不賄選，以乾淨的方式參與選舉。政治獻金依法設立專戶、依法申報；重要建設、採購與計畫依法辦理並公開資訊。</p>
<p><strong>鄉親託付的每一分資源，都應該知道花在哪裡；承諾的每一項建設，也應該看得到進度。</strong></p>
</section>
<section class="section" id="method">
<div class="num">02 / 做事的方法</div><h3>務實，是把事情一件一件做好</h3>
<div class="promise">
<div>守護乾淨宜居的環境</div><div>守護安心平安的社區</div>
<div>守護貼近鄉親的公所服務</div><div>守護公開透明的鄉政信任</div>
</div>
<p style="margin-top:20px">能做的事情，就積極去做；需要時間的事情，就把進度說清楚；依法不能做的事情，也應該誠實向鄉親說明。</p>
</section>
<section class="section" id="policy">
<div class="num">03 / 三灣的下一步</div><h3>三灣興，是讓家鄉有下一個十年</h3>
<div class="policy"><strong>農業</strong><span>推動智慧農業、改善農水路與生產環境，協助三灣梨、柑橘等在地農產提升價值與市場能見度。</span></div>
<div class="policy"><strong>青年</strong><span>建立青農與返鄉創業交流平台，讓想回家的年輕人，真正有機會留下來。</span></div>
<div class="policy"><strong>觀光</strong><span>串聯步道、農產、客庄文化與地方特色，發展小旅行，讓遊客走進來、留下來。</span></div>
<div class="policy"><strong>照顧</strong><span>持續推動社區共餐與長照資源，讓長輩有人陪伴、有人關心，減輕家庭照顧壓力。</span></div>
<div class="policy"><strong>交通</strong><span>持續爭取幸福巴士服務與聯外道路改善，讓就醫、通學與日常往返更加便利。</span></div>
<div class="policy"><strong>生命禮儀</strong><span>持續推動生命紀念園區相關工作，讓人生最後一程獲得應有的尊重與完善安排。</span></div>
</section>
<section class="section" id="experience">
<div class="num">04 / 為什麼站出來</div><h3>願意聽、願意到、願意負責</h3>
<p>我不敢說自己什麼都會，也不會說所有問題都能馬上解決。但我的工作經歷教會我三件事情：</p>
<div class="three">
<div class="card"><b>願意聽</b>鄉親的聲音，不只是聽見，更要理解真正的問題。</div>
<div class="card"><b>願意到</b>遇到事情，到現場了解，而不是只坐在辦公室裡判斷。</div>
<div class="card"><b>願意負責</b>面對問題想辦法；做了決定，就對結果負責。</div>
</div>
<p>離開三灣，我看過外面的世界；回到三灣，我更知道自己的根在哪裡。這一次，我選擇再往前一步，把多年第一線服務的經驗，帶到更完整的地方治理。</p>
</section>
